# Code audit: 2026-09-27

Baseline: `b096c91e7c3617225f6eec4a042286463d4a19e9`.

## Confirmed and fixed

| Priority | Problem | Correction and evidence |
| --- | --- | --- |
| P1 | Inherited `MODEL_ROUTER_STATE_DIR` overrides the installer's selected profile; inherited `MODEL_ROUTER_TARGET` can select another client during setup commands. | Bind both state aliases and the target in prepare, install, continuation and rollback subprocesses, and in all three service adapters. Regression failed before the fix; the actual embedded Node path resolver selected the synthetic profile after the fix. |
| P2 | A dangling macOS service-definition symlink is treated as absent, allowing the installer to write its target. | Treat symlinks as occupied paths. Regression proves the foreign target stays absent and no launchctl call occurs. |
| P2 | Linux writes the service under `~/.config` even when systemd uses a custom `XDG_CONFIG_HOME`. | Use the configured absolute directory; fall back for empty or relative values. Regression checks the generated unit destination. |
| P2 | Portable workers write the complete prompt into a pipe before starting deadline/cancellation checks. A child that never reads stdin can hang indefinitely. | Supply stdin from a private temporary file and reap a still-running child on runner errors. A real sleeping child and a 2 MB prompt reproduce the old hang and now reach `worker_timeout`. |
| P2 | Browser read/navigation reports `verified` after an initial redirect or unsuccessful load wait; link handling can proceed on the wrong page. | Require successful load and the requested initial URL. Seven synthetic broker tests cover correct pages, redirects, failed waits and stopping before a click. Added to CI. |
| P3 | The OpenClaw Windows preflight test searches for `npm ci` although the script invokes `npm.cmd ci`. Missing substrings can also accidentally satisfy an ordering comparison. | Match the real command and assert both commands exist before comparing their positions. Focused installer suite passes. |

## Coverage and limits

Repository-wide automated checks were combined with manual review of installer
checkpoints and rollback, platform adapters, worker lifecycle, local HTTP
handling, provider ladder, browser broker and verification helpers. This is
not a claim that every line of the large embedded upstream router received
manual review or that untested behavior has no defects.

Checks ran on macOS. Linux/systemd and Windows/Task Scheduler changes have
synthetic coverage, not fresh-host installation acceptance. No live profiles,
services, provider accounts, or user browser tabs were changed. Real provider
responses, UI integration and fresh-host installation remain outside this
offline audit. Existing documentation PR #2 is separate from these fixes.
